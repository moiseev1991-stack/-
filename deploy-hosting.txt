Что сделать на Plesk (без этого сайт не запустится):

1) Включить Node.js для домена, корень приложения = папка с package.json (обычно httpdocs).

2) После git pull на сервере выполнить:
   npm ci
   npm run build

3) Запуск: npm start  (или стартовый файл server.js в настройках Node).

4) SSL: выбрать сертификат (Let’s Encrypt), если включён редирект на HTTPS.

5) Удалить лишний index.html-заглушку в httpdocs, если мешает.

Репозиторий сам по себе «готов»; сборка и node_modules появляются на сервере после шагов 2–3.
