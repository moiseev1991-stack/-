Вариант A — Node.js (полный Next.js, редиректы из next.config работают)

1) В Plesk включить Node.js для домена, корень = папка с package.json (httpdocs).
2) На сервере: npm ci && npm run build && npm start (или стартовый файл server.js).
3) SSL: выбрать сертификат, если включён HTTPS-редирект.
4) Убрать лишний index.html-заглушку в корне, если мешает.

Вариант B — только статика (без Node: обычный Apache)

1) На GitHub: Actions → workflow "Static export" → последний успешный запуск.
2) Скачать артефакт static-site (папка out).
3) Содержимое out загрузить в httpdocs (заменить файлы), старый index.html удалить.
4) Редиректы из next.config на статике не работают — используются прямые арабские URL из меню.

Сборка static-site выполняется на Linux (GitHub); локально на Windows npm run build:static может падать.
